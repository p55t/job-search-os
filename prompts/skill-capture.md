
# Skill Capture Prompt

Use this prompt after a workflow has worked at least twice and feels worth reusing.

## Goal
Turn a repeatable job-search workflow into a Hermes skill or a durable repo note.

## Return format
1. Skill / workflow name
2. Trigger condition
3. Step-by-step procedure
4. Inputs and outputs
5. Common failure modes
6. What to store in `wiki/ops/` versus what to export as a Hermes skill

## Rule
If the workflow is still exploratory, keep it in `wiki/ops/change-log.md` and the experiment pages instead of promoting it.
