
# Experiment Template

Use this for a single job-search experiment.

## Hypothesis
What should improve, and why?

## Change
What exactly is different from the previous version?

## Metric
Pick one primary metric:
- reply rate
- recruiter screen rate
- interview conversion
- quality of shortlist fit

## Run window
How long will you run it before judging?

## Result
What happened?

## Decision
Keep, discard, or revise.

## Next step
What gets tested next?
